# Mark Buddy C. Baay — Personal Portfolio

## Files
- `index.html` — website structure and content
- `style.css` — visual design and responsive styling
- `script.js` — navigation, scroll effects, and contact form behavior
- `assets/` — optional images/assets

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `assets/`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save and wait for GitHub to publish the site.

## Before submission
